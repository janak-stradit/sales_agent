# Frontend Application Workspace

This directory is designated for the frontend application layer.
The frontend team can initialize their preferred framework (e.g., React, Next.js, Vue, or Vanilla JS) in this folder.

### Backend API Reference
* **API Base URL**: `http://localhost:8000/api/v1`
* **Interactive Swagger Documentation**: `http://localhost:8000/docs`
* **ReDoc API Reference**: `http://localhost:8000/redoc`
